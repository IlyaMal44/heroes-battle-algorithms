# Heroes Battle - Реализация игровых алгоритмов

## Описание проекта
Реализация ключевых алгоритмов для пошаговой стратегии "Heroes Battle".

## Реализованные алгоритмы

### 1. Генерация армии противника (`GeneratePresetImpl`)
**Задача**: Создать оптимальную армию компьютера в пределах 1500 очков.
- **Алгоритм**: Жадный алгоритм с оптимизацией по эффективности
- **Сложность**: O(K·M), где K=4 (типы юнитов), M=63 (позиции) → O(1)
- **Особенности**: Ограничение 11 юнитов каждого типа, случайное распределение позиций

### 2. Симуляция пошагового боя (`SimulateBattleImpl`)
**Задача**: Провести полную симуляцию боя между армиями.
- **Алгоритм**: PriorityQueue для управления очередью ходов
- **Сложность**: O(N log N), где N - общее количество юнитов
- **Особенности**: Сортировка по атаке, обработка смертей юнитов, логирование действий

### 3. Определение доступных целей (`SuitableForAttackUnitsFinderImpl`)
**Задача**: Найти юнитов противника, доступных для атаки.
- **Алгоритм**: Линейный поиск по рядам
- **Сложность**: O(R·C), где R=3 (ряды), C≤27 -> O(N)
- **Особенности**: Выбор крайних юнитов в рядах (левых/правых в зависимости от стороны атаки)

### 4. Поиск кратчайшего пути (`UnitTargetPathFinderImpl`)
**Задача**: Найти кратчайший путь между юнитами на поле с препятствиями.
- **Алгоритм**: A* (A-star) с эвристикой Чебышева
- **Сложность**: O(V log V), где V=567 (27×21 клеток поля)
- **Особенности**: Движение по 8 направлениям, учёт препятствий (других юнитов)
